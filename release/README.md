# release/ — завжди поточні бінарники

На відміну від [GitHub Releases](https://github.com/juv4uk/chess-tauri-zero/releases)
(версіоновані знімки — v0.0.1, v0.0.2, ...), файли тут **перезаписуються
на кожен реліз-вартий пуш** і завжди відповідають останньому коміту
`master`. Не версіоновані іменем файлу навмисно — версія вшита прямо
в сам бінарник (видно в заголовку вікна при запуску: `Chess Tauri
Zero vX.Y.Z`, береться з `app/src-tauri/tauri.conf.json`, не хардкод).

| Файл | Платформа |
|---|---|
| `chess-tauri-zero-current-linux-x86_64` | Linux, `x86_64-unknown-linux-gnu` |
| `chess-tauri-zero-current-windows-x86_64.exe` | Windows, `x86_64-pc-windows-gnu` (крос-компільовано) |

Обидва — portable-бінарники без Python усередині: клонуй репо, налаштуй
`.venv` за `readme.md`, поклади/запусти бінарник з цієї теки (або
з того шляху, куди вже поклав раніше — головне, щоб репо було поруч,
sidecar шукає `.venv`/`src/` відносно свого розташування в
`app/src-tauri/binaries/`).

**Хто оновлює:** щоразу, коли є реліз-вартий набір змін (не кожен
дрібний коміт з документацією) — перебілдити обидва (`cargo build
--release` + крос-компіляція під Windows, див.
`docs/tauri-app-uk.md`), скопіювати сюди з новими іменами (`current-*`,
без зміни назви), закомітити разом зі змінами коду в тому ж пуші.
